# 《天宝》剧本风格

## 一、文字

### 总则

- 时代是盛唐天宝末年。叙事用浅近文言夹白话，读起来要像史书节录，不要像古装剧台词。
- 只写已经发生的事实。数值、概率和反事实分支属于游戏设计；史事以 `docs/FACT_CHECK.md` 为准。没有核实的细节不写成确定的史实。没有把握时，写「史无明文」或「本游戏设定」。
- 不使用现代词语，例如「OK」「搞定」「数据」「团队」「战略层面」「压力山大」。

### 称谓

| 场合 | 用法 |
|---|---|
| 臣下称皇帝 | 陛下、圣上；内侍可以称「大家」（唐时宫中对天子的称呼） |
| 皇帝自称 | 朕 |
| 宰相、朝官自称 | 臣，或称「臣某」（如臣林甫、臣真卿） |
| 宦官自称 | 老奴（高力士）、奴婢（边令诚） |
| 太子自称 | 儿臣 |
| 贵妃自称 | 妾；私下称玄宗「三郎」 |
| 安禄山自称 | 臣胡人、臣 |
| 武将自称 | 臣、末将 |
| 称宰相 | 右相、左相、相公 |
| 称节度使 | 某镇节度、某帅、某公 |

### 年号与时间

- 天宝三载（744）正月起改「年」为「载」，本剧本一律写作「天宝十载」「天宝十四载」。
- 纪月用「正月」「二月」「冬十一月」。季节以春、夏、秋、冬标示。
- 不写公元年份。只有 UI 的注释和 FACT_CHECK 文档可以用公元年。

### 文体样式

- **奏疏摘要**：一到两句，先写事由，再写所请事项，不超过 120 字。
- **谏言**：一句话，符合说话人的口吻，不超过 60 字。
- **事件正文**：仿《通鉴》叙事，句子短，不加评论。属于反事实的事件，在末尾注「（反事实）」。
- **结局文字**：先写局面，再写余波。史实结局要注明史实；虚构结局要注明是「本游戏的结局」。

### 禁忌

- 不渲染死亡和血腥。马嵬、斩将一类情节只写处置结果。
- 安禄山的胡人身份只作为人物设定，不写成族群贬损的笑料。
- 杨贵妃不写成祸水；剧本把「致乱之由」交给制度与人事。

## 二、美术

美术方向以 `design/STYLE_GUIDE.md` 为准，资产 id 见 `docs/ART_LIST.md`。要点：

- 敦煌壁画与唐代绢本设色，用石青、石绿、赭石、朱砂、泥金。
- 服色依品级：三品以上服紫，四、五品服绯，六、七品服绿，八、九品服碧（青）。头戴软脚幞头，身穿圆领袍，系革带。三品以上佩金鱼袋，五品以上佩银鱼袋。
- 皇帝穿赭黄袍，戴折上巾。不画龙纹、团龙补子，不画明代乌纱帽硬翅，也不画补子。
- 所有图像都不带文字。
